# 자산과 공개 범위

## 포함

최신 설치본의 `game/`에 있는 필수 이미지, 모델, 텍스처, 음악, 영상과 코드, 기존 업데이트 자료를 포함합니다. 원본의 링크 파일은 실제 내용을 복사했습니다. 브랜딩 아이콘, C# 호스트와 설치기 소스, 기존 제작 도구도 포함합니다.

가장 큰 파일은 `game/assets/cinematic/mercy-opening.mp4`(약 172MB)입니다. 전체 게임 파일은 약 704MB이며 Git LFS로 바이너리 자산을 관리합니다. LFS 스토리지·트래픽 사용량은 GitHub 계정의 요금제와 정책에 따라 달라질 수 있습니다.

## 제외

- 로컬 계정·세션·세이브 및 WebView2 사용자 프로필.
- 배포 서명 개인키, `.signing/`, 환경 변수 파일과 인증 정보.
- 중복된 이전 설치본·설치 EXE·백업·테스트 프로필·중간 작업 디렉터리.
- `.openai/` 호스팅 메타데이터 및 기존 플랫폼 체크아웃 설정.

과거 제작 스크립트는 제작 참고 자료입니다. 실행 경로를 수정해야 할 수 있으며 빌드 단계가 아닙니다.

## 출처와 권리

기존 출처 기록은 `game/assets/credits.txt`를 원문 그대로 보존했습니다. 자산별 생성 과정이나 이용 조건이 모두 기록된 것은 아닙니다. 누락된 원저작권자·생성 서비스·라이선스를 추정해 새로 기재하지 않았습니다. 공개 저장소에 포함되었다는 사실만으로 모든 자산의 자유로운 재배포나 상업 이용을 허가하지 않습니다.

Three.js는 자체 MIT LICENSE를 포함하며 WebView2 SDK는 Microsoft의 고지를 포함합니다. 프로젝트 전체에 대한 포괄적 새 라이선스는 추가하지 않았습니다.

## 무결성

`docs/FILE-MANIFEST.json`에는 공개 스냅샷의 파일별 경로, 바이트 크기, SHA-256이 들어갑니다. 파일을 수정한 뒤 다음 명령으로 기록을 갱신할 수 있습니다.

```powershell
node .\scripts\Validate.mjs --write-manifest
node .\scripts\Validate.mjs
```

이 검사는 누락·해시 불일치·LFS 포인터만 내려받은 상태를 확인하며 실제 게임 플레이 테스트를 대체하지 않습니다.
